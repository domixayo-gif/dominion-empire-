# Dominion Empire — Creative Ad Studio

A responsive, single-page agency website for Dominion Empire. Built with plain HTML, CSS and JavaScript so it can be hosted as a static GitHub Pages site without a build step.

## What's included

- Responsive agency landing page for mobile and desktop
- UGC video ads, AI video ads, social media creatives, and ad concept/editing services
- Portfolio-style creative direction examples, clearly labelled as spec concepts
- Studio introduction and four-step creative process
- Enquiry form that prepares a WhatsApp message
- Mobile navigation, accessible labels, reduced-motion support, and basic social sharing metadata

## Before publishing

1. Open `script.js`.
2. Find `const WHATSAPP_NUMBER = "";`.
3. Add your WhatsApp number in international format using digits only. For Nigeria, use `234` followed by the number without the first zero. Example format: `2348012345678`.
4. Save and commit the change.

The contact form will explain that the number is not configured until you add it. No email address, client testimonials, campaign results, or social handles have been invented.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Choose **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish and provide the website URL.

## Customize the portfolio

The three portfolio tiles are illustrative spec-ad concepts, not claims of paid client work. Replace their visual sections in `index.html` with real project images and descriptions as your portfolio grows.

## Files

- `index.html` — page structure and copy
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation, year, and WhatsApp enquiry form
